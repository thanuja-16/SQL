window functions:
window function mainly used to finding rows, ranking
3 Types of functions
ranking function
i.row_number()
ii.rank()
iii.dense_rank()
1v. ntile()

aggregate functions:
avg()
max()
min()
count()
sum()

offset function:
first_value()
lag()
lead()

syntax of window function
select columlist,functionname over() as aliasname from table;

in window function represented by over():
partition by : it is used ti divided the data into group based on column .
order by : to sort the data into a order based on column.
