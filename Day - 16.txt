views: 
view is a virtual table or logical table
it only store  select sql query and doesn't store the data.
the views are created using select query.
Advantages of views:
1.security
2.to avoid unnecessary columns in table.
3.simplify complex queries.
4.to maintain readability.  
there are 2 types
1)simple view : the simple view is created one table does not contain any complex operations like joins, aggregates functions,clueses
(group by ,having) 
2)complex view : the view is created from more than one table ,does contain joins, aggregates functions and cluses.

syntax:
create view view_name select query;

simple view syntax:
create view view_name select query ;

complex view:
create view view_name select query;(select query using joins, cluses aggregate functions

to kwon table or view: show full tables;
show full tables where table_type='VIEW';

to create view table
create view emp_view as select emp_id,emp_name,salary from employee;
