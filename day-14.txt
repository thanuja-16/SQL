Subquery:
^^^^^^^^
to write a query inside another query.
the subquery enclosed within parenthesis.
EX: 
select query condition(subquery);
1.singlerow subquery
2.multirow subquery
3.nested subquery
4.corealeted subquery

1.singlerow subquery: the subquery returns only one row that is called single row subquery.
using >,<,=,>=,<= etc
select * from product where price=
(select max(price) from product;
select max(price) from product where price<
(select max(price) from product;
select * from product where price=
(select max(price) from product where price<
(select max(price) from product));
2.multirow subquery : the subquery returns more than one row that is called  multiple subquery
using any, all, in, some
any : if only one condition it retrieves the data.
select * from product where price< any
(select price from product where category='furniture');
all : to match all condition
select * from product where price< all
(select price from product where category='furniture');
in :
 
some: it works as sameas like the any
select * from product where price< some
(select price from product where category='furniture');

3.nested subquery : multi level of sulectbquery is called as nested subquery.
select * from product where price=
(select max(price) from product where price<
(select max(price) from product));

select max(price) as max_price from product;
