aggregate function:
the main purpose of aggregate function is used to perform mathematical functions in multiple rows and return single value.
1.count(*); :  count  it returns the no.of rows count value. 
select count(*) as total_count from product;
2.sum(column name); : 
select sum(quantity) from product;
3.avg(column name); : it returns a avg of all values in column
select avg(quantity) from product;
4.max(column name); : to return a maximum value in acolumn
select max(price) from product;
5.min(column name); : to return a mimimum value in column.
select min(price) from product;
