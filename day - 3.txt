Constrains :
Constrains are used to rules applied in tables columns. The main purpose of constrains are used to ensure data consistency, data integrity, data accuracy.
There are six constrains
1.unique
2.not null
3.primary key
4.foreign key
5.check
6.default

1.unique :
Ensure all the values are unique in a column
EX: stid
2.not null:
Every columns must be contain a value.
EX: name
3.Primary key:
Combination of not null and unique.
EX : ph:no, email, stid, adhar id 
4.Foreign key:
It is used to maintain the relationship between tables.
EX: customer , menu
5.Check:
The column values must be contain to above mention the range of values.
EX : age, marks
6.Defaut:
If in case no insert any data in that column that time it automatically to insert default value
EX : address
