set operators : it is used to combine the two or more select queries.
1.union  : it retrieves the both tables and remove duplicates all ignore
select * from old_student union select * from new_student;
2.unionall : it is same as the union but also takes duplicates
select * from oid_student union all select * from new_student; 
3.insert  : it takes the only common values ( in )         before 8.0.31 version doent work
select * from old_student intersect select * from new_student;
select * from old_student where in (select * from new_student);
4.except : it takes the first table it takes except the common values
select * from old_student except select * from new_student;    (not in)
select * from old_student where not in (select * from new_student);
